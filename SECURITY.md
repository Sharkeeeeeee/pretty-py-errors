# Security Policy

## Supported Versions

| Version | Supported |
| --- | :---: |

## Reporting a Vulnerability

Please do **not** open a public issue for security problems. Report them privately through [GitHub Security Advisories](https://github.com/Sharkeeeeeee/pretty-py-errors/security/advisories/new). You can expect an initial response within 7 days.
